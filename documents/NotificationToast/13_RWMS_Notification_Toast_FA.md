**این بخش چه کاری انجام می‌دهد؟**

Notification Foundation یک روش واحد برای پیام‌های کوتاه و موقت در سراسر سامانه فراهم می‌کند. Featureها از notify استفاده می‌کنند و مستقیماً به کتابخانه Toast وابسته نمی‌شوند.

**امکانات و خروجی قابل استفاده**

**•** اعلان Success، Error، Warning، Info و Loading.

**•** هماهنگی Toast با Light/Dark Mode.

**•** محل نمایش ثابت و قابلیت بستن.

**•** Wrapper مستقل برای امکان تعویض کتابخانه در آینده.

**نحوه استفاده**

**•** پس از عملیات موفق کوتاه مانند ثبت یا حذف، پیام Success مناسب نمایش داده شود.

**•** خطای Field با Toast جایگزین نشود؛ Field Error زیر همان ورودی نمایش داده شود.

**•** برای خطای عمومی Submit می‌توان Toast Error استفاده کرد.

**•** پیام Toast کوتاه و عملیاتی باشد و جزئیات طولانی داخل Dialog/Page قرار گیرد.

**قواعد و نکات مهم**

**•** از Toast برای هر تعامل کوچک استفاده نشود تا کاربر دچار اعلان‌زدگی نشود.

**•** Featureها مستقیماً sonner را import نکنند و فقط notify را استفاده کنند.

**•** پیام‌های حساس یا نیازمند تصمیم کاربر Toast نیستند؛ از Dialog/Confirm استفاده شود.
