**این بخش چه کاری انجام می‌دهد؟**

هدف این بخش ایجاد یک زبان بصری آرام، حرفه‌ای و پایدار برای یک سامانه سازمانی پیچیده است. صفحات نباید با رنگ، کارت، انیمیشن یا Widgetهای غیرضروری شلوغ شوند. تمام رنگ‌های اصلی از Design Tokenها می‌آیند و Light/Dark بدون تغییر Componentها کار می‌کند.

**امکانات و خروجی قابل استفاده**

**•** پالت اصلی آبی-سبز سازمانی با Primary #155E75 و Secondary #0D9488.

**•** Background، Surface، Text و Border به‌صورت Token تعریف شده‌اند.

**•** Dark Mode رسمی با پس‌زمینه تیره غیرمشکی و کنتراست کنترل‌شده.

**•** Theme انتخابی کاربر در مرورگر نگهداری می‌شود و در مراجعات بعدی حفظ می‌شود.

**•** رابط راست‌به‌چپ و فونت فارسی در سطح کل برنامه فعال است.

**نمای سریع**

| **موضوع**      | **راهنمای کاربردی**                     |
| -------------- | --------------------------------------- |
| **Primary**    | #155E75 — رنگ اصلی عملیات و انتخاب فعال |
| **Secondary**  | #0D9488 — Accent کنترل‌شده              |
| **Background** | #F8FAFC — پس‌زمینه اصلی روشن            |
| **Surface**    | #FFFFFF — کارت‌ها و سطوح اصلی           |
| **Text**       | #1E293B — متن اصلی                      |
| **Border**     | #E2E8F0 — خطوط و مرزبندی‌های آرام       |

**نحوه استفاده**

**•** در Componentها از کلاس‌های معنایی مانند bg-surface، text-foreground و border-border استفاده شود.

**•** رنگ‌های مستقیم مانند bg-white یا text-slate-800 برای عناصر Theme-dependent استفاده نشوند.

**•** رنگ‌های Success/Warning/Danger فقط برای بیان وضعیت واقعی استفاده شوند، نه تزئین.

**•** صفحات سازمانی با فضای سفید کافی، مرزبندی ظریف و Hierarchy روشن طراحی شوند.

**•** قبل از تأیید یک UI جدید، هر دو حالت Light و Dark و عرض موبایل بررسی شوند.

**قواعد و نکات مهم**

**•** زیبایی باید از نظم و خوانایی بیاید، نه از Gradient، Glass Effect و انیمیشن‌های زیاد.

**•** Sidebar روشن انتخاب شده تا محیط در استفاده طولانی سنگین نشود.

**•** Component جدید نباید Theme خود را مستقل از Tokenهای پروژه تعریف کند.

**•** هر Theme جدید در آینده باید فقط با تغییر Tokenها قابل اضافه شدن باشد.

**در ادامه پروژه**

**•** همه ماژول‌های Business باید بدون کد اضافه، در Light/Dark و RTL درست نمایش داده شوند.
