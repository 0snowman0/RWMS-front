**این بخش چه کاری انجام می‌دهد؟**

API Infrastructure تنها درگاه عمومی ارتباط Frontend با FastAPI است. Featureها به‌جای fetch پراکنده از apiClient استفاده می‌کنند. خطاها به ApiError استاندارد تبدیل می‌شوند و Hookهای سراسری امکان اضافه شدن رفتارهای آینده مانند 401/403 و Refresh Token را بدون بازنویسی Featureها فراهم می‌کنند.

**امکانات و خروجی قابل استفاده**

**•** متدهای مشترک GET، POST، PUT، PATCH و DELETE.

**•** استفاده خودکار از Base URL و Timeout مرکزی.

**•** پشتیبانی JSON و FormData.

**•** ApiError با status، message و data.

**•** تشخیص ساده Unauthorized، Forbidden، Validation، Server و Network Error.

**•** Extension Point برای beforeRequest، onUnauthorized، onForbidden و onError.

**•** امکان Retry کنترل‌شده درخواست بعد از Auth Refresh در آینده.

**نمای سریع**

| **موضوع**       | **راهنمای کاربردی**                                 |
| --------------- | --------------------------------------------------- |
| **Feature API** | Endpoint و Typeهای همان دامنه را می‌شناسد           |
| **apiClient**   | HTTP، Timeout، Header و Parse پاسخ را مدیریت می‌کند |
| **ApiError**    | شکل استاندارد خطای قابل استفاده در Frontend         |
| **API Hooks**   | نقطه توسعه برای Auth و خطاهای سراسری                |

**نحوه استفاده**

**•** Feature API فقط apiClient را صدا بزند و fetch مستقیم نداشته باشد.

**•** پیام و داده خام Backend در ApiError نگهداری می‌شود تا لایه بالاتر تصمیم بگیرد.

**•** رفتار سراسری 401/403 در Hookهای API ثبت می‌شود؛ apiClient نباید مستقیم Router را بشناسد.

**•** برای Upload از FormData استفاده شود تا Content-Type به‌درستی توسط Browser تعیین شود.

**•** فاز ۱ بدون Auth کار می‌کند؛ Extension Pointهای Auth فقط برای آینده آماده شده‌اند.

**قواعد و نکات مهم**

**•** API Client نباید منطق Category، Item یا Waybill داشته باشد.

**•** Redirect مستقیم به Login داخل shared/api انجام نشود.

**•** Retry عملیات Mutation نباید کورکورانه انجام شود.

**•** برای خطاهای جدید Backend بهتر است Mapping سراسری و مستند ایجاد شود.

**در ادامه پروژه**

**•** در فاز Auth، Token/Cookie و Refresh Flow فقط از طریق Hookهای موجود اضافه می‌شوند تا Featureها تغییر حداقلی داشته باشند.
