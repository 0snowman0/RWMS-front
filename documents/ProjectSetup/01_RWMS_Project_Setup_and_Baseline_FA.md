**این بخش چه کاری انجام می‌دهد؟**

این بخش خط مبنای فنی پروژه را مشخص می‌کند تا همه توسعه‌های بعدی روی یک ساختار پایدار، قابل Build و قابل نگهداری انجام شوند. نتیجه این مرحله یک پروژه React/TypeScript آماده توسعه با Tailwind، فونت فارسی، RTL و مسیرهای import استاندارد است.

**امکانات و خروجی قابل استفاده**

**•** پروژه بر پایه React، TypeScript و Vite آماده شده و Build تولیدی قابل استفاده دارد.

**•** Tailwind به‌عنوان لایه Utility CSS فعال است و Design Tokenهای پروژه روی آن سوار می‌شوند.

**•** فونت Vazirmatn برای رابط فارسی در پروژه بارگذاری شده است.

**•** Alias با علامت @ به پوشه src اشاره می‌کند تا importهای طولانی حذف شوند.

**•** RTL در سطح پایه برنامه فعال است تا همه صفحات فارسی از ابتدا رفتار درست داشته باشند.

**نحوه استفاده**

**•** همه توسعه‌های جدید باید داخل همین پروژه و با همین ساختار انجام شوند؛ از ایجاد پروژه موازی برای یک Feature خودداری شود.

**•** برای import فایل‌های داخل src تا جای ممکن از @/... استفاده شود.

**•** پس از هر تغییر زیرساختی مهم، npm run build اجرا شود تا خطاهای TypeScript و Build زود تشخیص داده شوند.

**•** فایل‌های آزمایشی موقت پس از پایان تست حذف شوند تا App.tsx و ساختار اصلی تمیز بماند.

**قواعد و نکات مهم**

**•** نسخه Node/npm و وابستگی‌ها در package.json مرجع پروژه هستند؛ وابستگی جدید فقط زمانی اضافه شود که نیاز واقعی وجود داشته باشد.

**•** از Hard-code کردن تنظیمات محیطی یا URL سرور در Componentها خودداری شود.

**•** RTL و فونت فارسی باید از سطح پایه تأمین شوند؛ هر صفحه نباید دوباره آن‌ها را تعریف کند.

**در ادامه پروژه**

**•** این خط مبنا برای تمام ماژول‌های فاز ۱ و فازهای بعدی ثابت می‌ماند مگر اینکه تصمیم معماری رسمی جدیدی ثبت شود.
