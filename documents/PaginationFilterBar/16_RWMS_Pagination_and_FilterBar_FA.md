**این بخش چه کاری انجام می‌دهد؟**

Pagination و FilterBar الگوی ثابت صفحات لیستی را کامل می‌کنند. Pagination با page/pageSize/total کار می‌کند و برای داده‌های Backend طراحی شده است. FilterBar فقط ظرف چیدمان فیلترهاست و نوع فیلتر هر Feature را تحمیل نمی‌کند.

**امکانات و خروجی قابل استفاده**

**•** نمایش بازه رکوردها و شماره صفحه فعلی.

**•** تغییر تعداد رکورد در صفحه با گزینه‌های متداول.

**•** قبلی/بعدی با Disabled state صحیح.

**•** FilterBar واکنش‌گرا با محل ثابت برای فیلتر و Action.

**•** دکمه پاک کردن فیلترها فقط هنگام وجود Filter فعال.

**•** آماده برای Search، Select، Date Range و فیلترهای Feature-specific.

**نحوه استفاده**

**•** Page و PageSize در State/URL/Hook Feature مدیریت شوند و با Query Backend ارسال شوند.

**•** با تغییر فیلتر اصلی معمولاً Page به ۱ برگردد.

**•** FilterBar فقط Layout است؛ Search یا Category Filter داخل Feature تعریف می‌شود.

**•** اگر Backend total ارائه می‌دهد، همان مقدار مبنای Pagination قرار گیرد.

**قواعد و نکات مهم**

**•** برای لیست‌های بزرگ، همه رکوردها یکجا دریافت نشوند.

**•** فیلترهای فعال باید قابل تشخیص و Reset باشند.

**•** فیلترهای پیچیده در صورت نیاز می‌توانند در آینده Drawer/Advanced Filters داشته باشند بدون تغییر Pagination.
