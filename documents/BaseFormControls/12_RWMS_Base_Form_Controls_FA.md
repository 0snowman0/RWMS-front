**این بخش چه کاری انجام می‌دهد؟**

کنترل‌های پایه فرم ظاهر و رفتار مشترکی برای ورودی‌های معمول سامانه فراهم می‌کنند. فرم‌های ثابت و فرم‌های داینامیک آینده باید از همین کنترل‌ها یا Componentهای استاندارد توسعه‌یافته از آن‌ها استفاده کنند.

**امکانات و خروجی قابل استفاده**

**•** Input با حالت Normal، Invalid و Disabled.

**•** Textarea با ارتفاع پایه و Resize عمودی.

**•** Select استاندارد و Theme-aware.

**•** Checkbox با Label اختیاری.

**•** هماهنگی با FormField و پیام خطا.

**نحوه استفاده**

**•** Field فرم با FormField بسته‌بندی شود تا Label و Error یکدست باشند.

**•** برای Field نامعتبر، وضعیت invalid کنترل فعال شود.

**•** کنترل Domain-specific مانند DatePicker یا AsyncSelect بعداً به همین UI Kit اضافه می‌شود، نه اینکه داخل هر Feature ظاهر جدا ساخته شود.

**•** Dynamic Form Engine در آینده بر اساس type تعریف‌شده، Control مناسب را انتخاب می‌کند.

**قواعد و نکات مهم**

**•** Native Select فعلی برای نیازهای پایه مناسب است؛ Select پیچیده جستجویی فقط وقتی نیاز واقعی وجود داشت اضافه شود.

**•** ظاهر Controlها با Tokenهای Theme کنترل می‌شود و نباید رنگ ثابت داشته باشند.

**•** Accessibility مانند label/htmlFor در فرم‌های واقعی رعایت شود.
