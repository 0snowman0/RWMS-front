**این بخش چه کاری انجام می‌دهد؟**

این بخش قاب ثابت کل برنامه را فراهم می‌کند. Routeها Page مناسب را داخل MainLayout نمایش می‌دهند و MainLayout مسئول Sidebar، Header و فضای محتوای اصلی است. در موبایل Sidebar به Drawer تبدیل می‌شود تا فضای صفحه حفظ شود.

**امکانات و خروجی قابل استفاده**

**•** Routeهای تو در تو با Layout مشترک.

**•** Sidebar ثابت در دسکتاپ و Drawer در نمایشگر کوچک.

**•** Header واکنش‌گرا با کاهش عناصر کم‌اهمیت در عرض کم.

**•** Outlet برای نمایش Page فعال بدون تکرار Layout.

**•** امکان اضافه کردن Routeهای Feature بدون تغییر ساختار ظاهری اصلی.

**نحوه استفاده**

**•** هر Page جدید از Router ثبت می‌شود و محتوای خود را از Layout جدا نگه می‌دارد.

**•** JSX مربوط به طراحی Page داخل فایل Router نوشته نشود.

**•** آیتم‌های Sidebar صرفاً مسیرهای قابل ناوبری را نشان می‌دهند؛ منطق کسب‌وکار داخل Sidebar قرار نگیرد.

**•** در موبایل با انتخاب یک مسیر، Drawer بسته می‌شود.

**•** Pageها min-height کل Screen تعریف نکنند؛ ارتفاع و Scroll توسط Layout مدیریت می‌شود.

**قواعد و نکات مهم**

**•** Layout باید سبک و پایدار بماند؛ Feature-specific UI وارد آن نشود.

**•** برای فاز ۱، Login/RBAC عمداً وارد ناوبری نشده است.

**•** افزودن Header Action جدید فقط در صورت کاربرد عمومی و دائمی انجام شود.

**در ادامه پروژه**

**•** در فازهای بعدی، Navigation می‌تواند بر اساس Auth/Permission فیلتر شود بدون بازطراحی App Shell.
