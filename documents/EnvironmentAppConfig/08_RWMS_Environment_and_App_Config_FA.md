**این بخش چه کاری انجام می‌دهد؟**

این بخش تنظیمات وابسته به محیط را متمرکز می‌کند تا توسعه، تست و Production بدون ویرایش Componentها قابل تغییر باشند. Frontend فقط تنظیمات عمومی و قابل مشاهده را از Vite Environment می‌خواند.

**امکانات و خروجی قابل استفاده**

**•** نام برنامه، Base URL API و Timeout از Environment خوانده می‌شوند.

**•** پشتیبانی طبیعی از development و production mode.

**•** حذف اسلش اضافی انتهای Base URL برای جلوگیری از URL ناسالم.

**•** Default امن برای Timeout در صورت نبود مقدار اختیاری.

**نحوه استفاده**

**•** URL Backend فقط در فایل Environment تنظیم شود، نه داخل Page یا API Feature.

**•** .env.example باید فهرست متغیرهای لازم را برای توسعه‌دهنده بعدی نشان دهد.

**•** بعد از تغییر فایل Environment، Dev Server یک بار Restart شود.

**•** برای Production فایل Environment مناسب Deploy تعریف شود.

**قواعد و نکات مهم**

**•** هر متغیر VITE_ قابل مشاهده در Browser است؛ Secret در Frontend قرار نگیرد.

**•** Database Password، JWT Secret و Private API Key فقط Backend هستند.

**•** متغیر جدید Environment باید در Config مرکزی خوانده و اعتبارسنجی شود.

**در ادامه پروژه**

**•** هنگام آماده‌سازی سرور مشتری فقط Base URL و تنظیمات محیطی تغییر می‌کنند؛ Featureها نباید نیاز به ویرایش داشته باشند.
