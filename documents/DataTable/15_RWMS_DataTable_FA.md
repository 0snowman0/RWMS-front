**راهنمای 15**

**DataTable Foundation**

جدول عمومی، Theme-aware و آماده استفاده در لیست‌های سازمانی

|     | **هدف این سند**<br><br>این سند برای استفاده مجدد در ادامه توسعه RWMS تهیه شده است؛ تمرکز آن روی نحوه استفاده، حدود مسئولیت، امکانات، قواعد و نکات مهم است و وارد جزئیات پیاده‌سازی داخلی نمی‌شود. |

**این بخش چه کاری انجام می‌دهد؟**

DataTable پایه نمایش رکوردها در صفحات لیستی است. جدول فقط مسئول نمایش Column و Row است و منطق Query، Filter یا Pagination را داخل خود جمع نمی‌کند؛ این تفکیک باعث می‌شود برای Featureهای مختلف قابل استفاده بماند.

**امکانات و خروجی قابل استفاده**

**•** تعریف Column به‌صورت Type-safe.

**•** نمایش Header و Cell سفارشی.

**•** پشتیبانی از Loading و Empty State.

**•** Scroll افقی کنترل‌شده در عرض کم.

**•** Hover و Border هماهنگ با Theme.

**•** بسته‌بندی TanStack Table پشت API داخلی RWMS.

**نحوه استفاده**

**•** هر Feature Columnهای خودش را تعریف می‌کند و data آماده را به DataTable می‌دهد.

**•** Action Column مانند مشاهده/ویرایش/حذف در همان Feature تعریف شود.

**•** برای Loading از prop مربوط استفاده شود و Empty State با متن مناسب Context تنظیم شود.

**•** Query و Pagination بیرون DataTable مدیریت شوند.

**قواعد و نکات مهم**

**•** جدول عمومی نباید منطق Item، Waybill یا Request را بشناسد.

**•** از قرار دادن Form پیچیده داخل Cell تا جای ممکن پرهیز شود.

**•** برای تعداد زیاد رکوردها Server-side Pagination مبنا است، نه دریافت کل داده در Browser.

**•** قابلیت‌های Sort/Selection فقط وقتی نیاز Feature مشخص شد به‌صورت کنترل‌شده اضافه شوند.

**در ادامه پروژه**

**•** لیست‌های Category، Item، Waybill، Request و Warehouse از همین DataTable استفاده خواهند کرد.
